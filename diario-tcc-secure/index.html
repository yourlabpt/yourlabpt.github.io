Como recuperar noutro dispositivo

  1. Guarde o ficheiro JSON da cópia encriptada (Ficheiros, iCloud, Drive).
  2. Abra esta app no novo telemóvel (ou após limpar a cache).
  3. Em “Criar diário”, escolha Recuperar cópia encriptada.
  4. Desbloqueie com o mesmo código mestre da cópia.

Também pode importar a cópia em Dados enquanto o diário estiver desbloqueado. Sem o código mestre da cópia, os dados não podem ser lidos.

Privacidade

A aplicação é local e não envia os registos para servidores. O formulário usa palavras discretas (“atalho”, “deslize”) para quem lê o ecrã sem contexto. Guarde as cópias encriptadas fora do navegador. A cópia CSV é legível; guarde-a apenas num local seguro.

Versão da app: —. Se os botões do formulário não responderem, feche completamente a app e abra de novo para atualizar.
